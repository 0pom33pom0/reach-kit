# reach-kit

> ⚠️ **สถานะ: กำลังพัฒนา — ยังใช้งานไม่ได้**
> ตอนนี้มีเพียงเอกสารออกแบบ ([spec](docs/superpowers/specs/2026-10-09-reach-kit-design.md)) ยังไม่มีโค้ด
> กด ⭐ Watch ไว้ แล้วรอเวอร์ชัน `v1.0.0`

เครื่องมือให้ AI agent (เช่น Claude Code) **อ่านและค้นข้อมูลจากอินเทอร์เน็ต รวมถึงอ่านคอมเมนต์** ได้หลายแพลตฟอร์ม
ทั้งเว็บทั่วไป, YouTube, TikTok, X, Facebook, Reddit, **Pantip**, GitHub, Hacker News, ArXiv และ RSS

## ทำไมต้องทำใหม่

เครื่องมือแนวนี้ที่มีอยู่ (เช่น agent-reach) ใช้งานได้ดี แต่มีจุดที่เรากังวล:

- ติดตั้งเครื่องมือภายนอกหลายตัวแบบไม่ล็อกเวอร์ชัน
- มีช่องทางอัปเดตที่ให้ AI ไปอ่านคำสั่งจากเว็บแล้วรันตาม — ถ้าวันหนึ่งต้นทางถูกแฮก ของไม่ดีจะเข้าเครื่องเราทันที
- เก็บคุกกี้ล็อกอินของเรา, `doctor` บอกว่าใช้ได้ทั้งที่ใช้ไม่ได้, คู่มือไม่ตรงกับโค้ด

reach-kit จึงยึดหลักนี้:

| หลักการ | รายละเอียด |
|---|---|
| 🔒 ไม่มี dependency ภายนอก | ใช้แค่ Python standard library (`dependencies = []`) |
| 🚫 ไม่อัปเดตตัวเอง | ไม่มี telemetry, ไม่ดึงคำสั่งจากเว็บมารัน — อัปเดตเมื่อคุณเปลี่ยนเวอร์ชันเอง |
| 🍪 ไม่เก็บคุกกี้ | ค่าเริ่มต้นไม่ล็อกอิน; ถ้าจำเป็นต้องสั่งเองทุกครั้ง |
| 💬 อ่านคอมเมนต์ได้ | เลือกจำนวน, เรียงตามยอดไลก์/ล่าสุด, มีคำตอบซ้อน |
| 📦 ผลลัพธ์รูปแบบเดียว | ทุกแพลตฟอร์มได้ JSON/markdown หน้าตาเดียวกัน ประหยัดโทเคน |
| 🩺 ไม่โกหก | `reach doctor` ทดสอบจริง; ถ้าดึงไม่ได้จะบอกเหตุผลและวิธีแก้ |
| 🛡️ กัน prompt injection | เนื้อหาจากเว็บถูกทำเครื่องหมายว่าเป็น "ข้อมูล" ไม่ใช่ "คำสั่ง" |
| 👀 อ่านโค้ดได้ทั้งหมด | ตั้งใจให้คนทั่วไปอ่านทั้งโปรเจกต์ได้ในไม่กี่สิบนาที |

## ใช้งานได้ 3 แบบ

1. **คำสั่งใน Terminal** — `reach read <ลิงก์>`, `reach comments <ลิงก์>`
2. **Skill ของ Claude Code** — Claude รู้เองว่าเมื่อไรควรใช้คำสั่งไหน
3. **MCP server** — ใช้กับ AI agent ตัวอื่นที่รองรับ MCP

## ตัวอย่างคำสั่ง (ตามแผน)

```bash
reach read https://pantip.com/topic/43000000 --comments
reach comments https://www.youtube.com/watch?v=xxxx --limit 100 --sort top
reach transcript https://www.youtube.com/watch?v=xxxx --lang th,en
reach search "วิธีทำคอนเทนต์ TikTok"
reach doctor
```

## แพลตฟอร์มที่รองรับ (ตามแผน)

| แพลตฟอร์ม | เนื้อหา | คอมเมนต์ | ต้องล็อกอินไหม |
|---|---|---|---|
| เว็บทั่วไป / ค้นหาเว็บ | ✅ | — | ไม่ |
| YouTube | ✅ ข้อมูลคลิป + ซับ | ✅ | ไม่ |
| TikTok | ✅ | 🟡 ขึ้นกับ TikTok | ไม่ |
| X / Facebook / Instagram | 🟡 โพสต์สาธารณะ | ❌ | ไม่ (เปิดคุกกี้ได้ถ้าจำเป็น) |
| Reddit | ✅ | ✅ | ไม่ แต่อาจต้องสร้าง Reddit app ฟรีของตัวเอง |
| Pantip | ✅ | ✅ | ไม่ |
| GitHub | ✅ | ✅ | ใช้ `gh` |
| Hacker News / ArXiv / RSS | ✅ | ✅ (HN) | ไม่ |

## สิ่งที่ต้องมี

- Python 3.9 ขึ้นไป (Mac มีให้อยู่แล้ว)
- [`yt-dlp`](https://github.com/yt-dlp/yt-dlp) สำหรับ YouTube / TikTok / X / Facebook — `brew install yt-dlp`
- [`gh`](https://cli.github.com) (ไม่บังคับ) สำหรับ GitHub
